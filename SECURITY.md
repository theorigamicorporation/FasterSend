# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/thereisnotime/FasterSend/security/advisories/new).

Include the affected version (image tag or commit SHA), steps to reproduce and the impact you observed. We will acknowledge the report, keep you updated on the fix and credit you in the advisory unless you prefer otherwise.

## Supported versions

Only the latest release and the `main` branch receive security fixes.
